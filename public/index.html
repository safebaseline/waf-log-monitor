更新 Bearer Token

在浏览器中打开 websaas.cn 攻击日志页面，按 F12 → 网络（Network）→ 任选一个 cloud-waf 请求 → 请求头里复制 Authorization: Bearer 后面的整串，粘贴到下面。Token 更新后会立即重新查询。

⛔ 加入 IP 黑名单（云 WAF 全站封禁）

将 IP 提交到云 WAF 访问控制（ACL），对当前监控的全部站点生效；在平台「访问控制」页面可管理已有规则。
