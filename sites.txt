# 用法：
#   1. 每行一个站点，格式：域名 或 域名:端口（与云 WAF 查询键一致）
#      例如：www.campus1.example.edu:443、oa.campus1.example.edu:9090
#   2. 行内空格后的内容视为备注，如：jw.campus1.example.edu 教务系统
#   3. 以 # 开头的行是注释，空行忽略
#   4. 删除或注释掉某行 = 停止采集该站点；新增一行 = 纳入采集
#      （新纳入的站点会自动回拉近 24 小时历史）
#   5. 修改保存后，点页面右上角「立即刷新」立即生效，
#      或等待下一轮自动轮询（10 分钟）生效，无需重启服务
#   6. 清空本文件全部站点（或删除本文件）= 恢复自动同步账号全部站点
# ============================================================
