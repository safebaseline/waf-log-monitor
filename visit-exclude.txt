# 用法：
#   1. 每行一个站点，两种写法均可：
#      - 域名:端口  → 精确排除该查询键，如 www.campus1.example.edu:443
#      - 域名       → 整站排除（带/不带端口的所有变体一并排除）
#   2. 行内空格后为备注；# 开头为注释；空行忽略
#   3. 修改保存后点页面「立即刷新」或等下一轮轮询生效，无需重启
#   4. 清空/删除本文件 = 恢复全部站点采集
#   5. 已入库的历史数据保留，仍可在页面筛选查看
